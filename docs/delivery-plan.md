# 開発・決定計画

## 1. 段階開発

### Phase 0: 基盤と教材契約

成果物:

- iOSプロジェクトとテストターゲット
- Design Tokenと主要コンポーネント
- 問題・選択肢・タグ・音声マニフェストのv1型
- コンテンツ検証ツール
- セッション状態機械
- ローカル保存とテスト用の承認済み教材パック

完了条件:

- 不正な列挙値、欠落正解、破損チェックサムを公開前に拒否する。
- 20問の状態遷移と途中復帰が自動テストで通る。

### Phase 1: E級縦切り

成果物:

- オンボーディング、ホーム、E級問題、中間結果、総合結果
- 2話者音声、自動再生、0.8倍／1.0倍
- 回答直後保存、途中復帰
- キャラクター6表情の差し替え可能な表示層
- 日本語・インドネシア語UI

完了条件:

- 実機またはシミュレーターで20問を通して完了できる。
- 回答前に問題文が画面・VoiceOverへ露出しない。
- 強制終了後に、重複なく最後の完了問題から再開できる。

### Phase 2: D級・生活図鑑MVP

成果物:

- 空港、ワルン、コンビニ、Grab
- 行動ツリー、解放条件、達成率
- 復習優先度と弱点補強
- 教材管理・レビューフローとの連携
- コンテンツパック更新

完了条件:

- 同じ教材を級別入口と生活図鑑入口から利用できる。
- 解放根拠が再現可能で、設定版を記録する。
- 公開済み教材を上書きせず版管理できる。

### Phase 3: オフライン・品質・公開準備

成果物:

- 最低10問のオフライン学習
- 冪等同期、再接続、破損コンテンツ回復
- VoiceOver、Dynamic Type、Reduce Motion
- 音声中断、イヤホン・Bluetooth経路変更
- 性能計測、プライバシー表示、データ削除導線

完了条件:

- オフライン回答が再接続後に一度だけ同期される。
- 音声開始と問題表示が性能目標を満たす。
- 日本語・インドネシア語で主要フローのUIテストが通る。

### Phase 4: C級

- 病院、薬局、銀行、SIM、配送、家、警察、行政、職場
- 高度な接辞、受動、口語・標準語差
- 定型応答と実戦チェック

### Phase 5: B〜A級AI評価

- 録音、作文、要約、面接、ロールプレイ
- 音声認識とAI評価
- ルーブリック、再評価、人間レビュー
- モデル更新時の基準回答回帰試験

Phase 5は、固定問題基盤、教材運用、録音データ方針、外部サービスの実環境が成立するまで開始しない。

## 2. Definition of Done

各機能は次を満たして完了とする。

1. 仕様と受入条件が `docs/` に存在する。
2. 型安全な実装で、強制アンラップや秘密情報の埋め込みがない。
3. 成功、想定失敗、キャンセルまたは繰り返し操作をテストする。
4. 実アプリスキームがビルドできる。
5. 見た目の変更はシミュレーターで直接操作して確認する。
6. Dynamic Type、VoiceOver、ライト／ダーク、日・インドネシア語を影響範囲に応じて確認する。
7. 音声変更は中断、再生回数、次問先読みを確認する。
8. 永続化変更は旧データ移行、途中復帰、再起動を確認する。
9. 未実施確認と環境上の阻害要因を報告する。

## 3. コンテンツ公開ゲート

公開可能な問題は次をすべて満たす。

- 正解が一意である。
- 誤答に学習上の理由がある。
- 級、文法、語彙、シナリオタグが付いている。
- 2話者方針との整合が取れている。
- 音声の自動検査と人間レビューを通過している。
- 文字非表示でも解答可能である。
- 正解・解説・音声の版が固定されている。
- 日本語・インドネシア語の必要な表示が揃っている。

## 4. リスクと対策

| リスク | 影響 | 対策 |
| --- | --- | --- |
| TTSの不自然さ | 音声学習の中心価値が崩れる | 話者を早期固定、発音辞書、人間レビュー、差し替え可能な音声ID |
| 教材確認量 | 公開が止まる | 単語・句・文の再利用、タグ一括管理、優先シナリオから投入 |
| 20問の離脱 | 学習習慣が成立しない | 10問チェックポイント、復帰、演出5秒以内、計測 |
| ゲーム要素過剰 | 学習速度が落ちる | 成果と結び付く演出だけ、スキップ、問題画面を簡素化 |
| 検定と実用の不一致 | 片方の目的を満たさない | 行動タグと検定タグを併記し、カバレッジを別々に可視化 |
| AI採点の揺れ | 信頼を失う | 版付きルーブリック、基準回答、再評価、人間確認 |
| 録音・個人情報 | 法務・信頼リスク | 最小送信、保存期間、削除、アクセス制御、ログ除外 |
| キャラクター権利 | 公開不能 | 参照と本番素材を分離し、制作・利用権を記録 |

## 5. 決定ゲート

以下は未確定であり、該当実装を公開可能にする前に決定する。

| 決定 | 必要になる時点 | 決定までの扱い |
| --- | --- | --- |
| 正式アプリ名・キャラクター名 | ストア素材・ローカライズ確定前 | 内部名 `Kentei` / `LearningCompanion` を使用 |
| Bundle ID・Signing Team | 実機配布・CI署名前 | シミュレーター用 `com.example.*` 以外は推測しない。正式値なしで配布・アーカイブしない |
| キャラクター素材の権利 | アプリ組込み前 | 参照資料のみ。最終素材として配布しない |
| 検定名称・準拠表現 | 公開コピー・教材監修前 | 「級相当」と表記し、公式認定を示唆しない |
| バックエンド・認証・DB・ストレージ | 実API連携開始前 | プロトコルと契約だけを定義しSDKを追加しない |
| TTS・音声認識・AIモデル | 音声生成・B級開発前 | `speaker_id`、`model_version` で抽象化 |
| 録音保存期間・削除SLA | 録音機能開発前 | 録音機能を公開しない |
| 課金方式 | 有料機能開発前 | 学習進行を制限しない |
| 正式な合格判定 | 検定モードの合否表示前 | 習得・行動達成のみ表示 |
| オフライン範囲 | Phase 3開始時 | MVP最低10問を保証 |

## 6. 最初の実装順

1. 問題・音声・タグのv1型とバリデーション
2. セッション状態機械と20問のテスト
3. 回答、途中復帰、習得状態のローカル保存
4. 音声再生と先読み
5. E級の問題画面
6. 中間・総合結果
7. ホームとオンボーディング
8. D級と生活図鑑
9. 同期・オフライン・アクセシビリティの公開品質化

最初の縦切りは、静的な承認済み教材パックで動作させてよい。ただし外部サービスが必要な機能をモックだけで完成扱いにしない。
