## 2. Definition of Done

各機能は次を満たして完了とする。

1. 仕様と受入条件が `docs/` に存在する。
2. 型安全な実装で、強制アンラップや秘密情報の埋め込みがない。
3. 成功、想定失敗、キャンセルまたは繰り返し操作をテストする。
4. 実アプリスキームがビルドできる。
5. 見た目の変更はシミュレーターで直接操作して確認する。
6. Dynamic Type、VoiceOver、ライト／ダーク、日・インドネシア語を影響範囲に応じて確認する。
7. 音声変更は中断、再生回数、次問先読みを確認する。
8. 永続化変更は旧データ移行、途中復帰、再起動を確認する。
9. 未実施確認と環境上の阻害要因を報告する。

## 3. コンテンツ公開ゲート

公開可能な問題は次をすべて満たす。

- 正解が一意である。
- 誤答に学習上の理由がある。
- 級、文法、語彙、シナリオタグが付いている。
- 2話者方針との整合が取れている。
- 音声の自動検査と人間レビューを通過している。
- 文字非表示でも解答可能である。
- 正解・解説・音声の版が固定されている。
- 日本語・インドネシア語の必要な表示が揃っている。

## 4. リスクと対策

| リスク | 影響 | 対策 |
| --- | --- | --- |
| TTSの不自然さ | 音声学習の中心価値が崩れる | 話者を早期固定、発音辞書、人間レビュー、差し替え可能な音声ID |
| 教材確認量 | 公開が止まる | 単語・句・文の再利用、タグ一括管理、優先シナリオから投入 |
| 20問の離脱 | 学習習慣が成立しない | 10問チェックポイント、復帰、演出5秒以内、計測 |
| ゲーム要素過剰 | 学習速度が落ちる | 成果と結び付く演出だけ、スキップ、問題画面を簡素化 |
| 検定と実用の不一致 | 片方の目的を満たさない | 行動タグと検定タグを併記し、カバレッジを別々に可視化 |
| AI採点の揺れ | 信頼を失う | 版付きルーブリック、基準回答、再評価、人間確認 |
| 録音・個人情報 | 法務・信頼リスク | 最小送信、保存期間、削除、アクセス制御、ログ除外 |
| キャラクター権利 | 公開不能 | 参照と本番素材を分離し、制作・利用権を記録 |
